# Classic Baby Mobs

Tiny Takeover (Minecraft 26.1) gave about 39 baby mobs brand-new models and textures. **Classic Baby Mobs** brings back how they looked before, the big-headed, scaled-down-adult babies of 1.21.11 and earlier. You choose **per mob** which look you want.

## Features

- **Per-mob choice.** Each baby mob has its own toggle: *Classic* (pre-Tiny Takeover) or *New* (26.x). Keep the new kittens but bring back the old calves, or any mix you like.
- **Master switch** plus **All Classic** / **All New** buttons.
- **Changes apply instantly.** Open the menu from the pause screen and watch the babies around you change. No resource reload needed.
- **Faithful.** Each classic baby is rebuilt from 1.21.11's own model geometry and baby proportions, uses the adult texture like 1.21.11 did, and keeps 1.21.11's baby-specific animation quirks (sitting kits, wolf pups, polar bear cubs, snifflets, hoglets and so on).
- **Details too.** Sheep wool, cat collars, wolf collars, horse markings, trader-llama blankets, drowned outer layers, villager outfits and armor on baby zombies and piglins all switch along with their mob.
- **Client-side only.** It works on any server, and nothing changes for other players.

## Covered mobs (39)

Chicken, Cow, Mooshroom, Pig, Sheep, Goat, Rabbit, Horse, Donkey, Mule, Skeleton Horse, Zombie Horse, Camel, Llama, Trader Llama, Strider, Cat, Ocelot, Wolf, Fox, Armadillo, Bee, Panda, Polar Bear, Sniffer, Axolotl, Dolphin, Squid, Glow Squid, Turtle, Hoglin, Zoglin, Piglin, Zombified Piglin, Villager, Zombie, Husk, Drowned, Zombie Villager.

## Opening the menu

- With **[Mod Menu](https://modrinth.com/mod/modmenu)** installed: Mods → Classic Baby Mobs → Configure.
- Or bind a key: Options → Controls → Key Binds → *Classic Baby Mobs* → "Open Classic Baby Mobs menu" (unbound by default).
- Settings are saved in `config/classic_baby_mobs.json`.

## Requirements

- Minecraft Java Edition **26.3**
- Fabric Loader 0.20.1+
- Fabric API
- Mod Menu (optional)

## Notes

- Only looks change. Hitboxes, sounds and behaviour stay as they are in 26.x.
- Tiny Takeover also remodelled the **adult** rabbit, so its texture no longer fits the old rabbit shape. Classic baby rabbits use the original 1.21.11 rabbit textures, which ship with this mod.
- Mods that replace entity models (for example Entity Model Features or Fresh Animations) may override the classic models for the mobs they change.

## Bedrock Edition

A Bedrock resource pack is available too. One version has a toggle for each mob in the pack's Settings (gear) screen; the other makes every baby classic.
